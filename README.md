# BankWidget

Краткое описание проекта, его цели и задачи.
Проект работает с банковскими операциями клиентов. Позволяет наглядно работать с данными в личном кабинете клиента.

Статус: в разработке

## <a id="title1">Установка</a>

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/olgapythonwq/BankWidget.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd ваш_проект
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## <a id="title1">Тестирование</a>

Все тесты находятся в пакете tests. Фикстуры вынесены в файл conftest.py. Процент покрытия тестами находится в файле 
index.html (можно открыть в браузере). Тестирование проводилось с использованием библиотеки pytest.

Для запуска тестов выполните команду:
```bash
pytest
```
